# D&D Beyond transfer prototype

## Verified on 2026-09-05

The signed-in homebrew magic-item creator accepts automated entry through its
visible UI. The first test populated an **unsaved** draft named
“101 Heads — Hydra Recurve Longbow”, with Weapon / Longbow as its base,
Unknown Rarity, and the full formatted major Northern Swarm rules.
The user subsequently selected Create. The continuation below saved one modifier
on that item; nothing was publicly published or added to a character.

The description is generated by `src/components/dndbeyond-export.ts` from the
same `WeaponCard` used for PNG export. It escapes content and emits simple
paragraphs, headings, and line breaks. It is a formatter, not an importer or API
client, and is not yet exposed as a forge button.

## Observed workflow

1. Open the homebrew magic-item creator and choose Create from Scratch.
2. Fill name, rarity, base item type, and base weapon.
3. Open the description toolbar's Source code dialog, insert generated HTML,
   and select Ok. This updates the form only.
4. Review before selecting Create Magic Item.

Beyond explicitly defers advanced character features until after creation.
The selected Longbow was grouped under 5.5e Core Rules; do not assume its
default damage, properties, or mastery match this campaign.

## Saved-item continuation

Prototype editor: https://www.dndbeyond.com/homebrew/creations/magic-items/11957016-101-heads-hydra-recurve-longbow/edit

Through Add a Modifier, selected **Bonus → Magic**, Fixed Value **1**, leaving
ability, dice, duration, and attunement blank/default. Saved the modifier and
then selected the parent editor's Save Changes. The reloaded table confirms
exactly one row: `Bonus - Magic`, fixed value `1`.

Inspected but did not save speculative modifiers:

- Set offers ability scores, speeds, armor, extra attacks and Unarmed Damage
  Die, but no weapon damage die or range override.
- Set Base offers four senses only.
- Damage offers damage types and attack categories (including Longbow), but
  does not explicitly indicate that it replaces the base damage die. Do not
  treat an extra damage modifier as a verified base-die replacement.
- Bonus offers Weapon Attack Range Multiplier, not independent normal/long
  range fields. One multiplier cannot map 150/600 to 200/700.
- Additional Information contains charge controls, notes, weight, images and
  tags; no direct base damage or range fields were exposed there.

This is evidence of successful form/modifier automation, **not** verified
character-sheet parity. The description's 1d6 and 200/700 values do not override
the native Longbow automatically. Native properties/mastery also need review.

## Not yet verified

### Character test, 2026-09-06

With permission, added one companion custom Weapon action to the designated
character, leaving existing equipment unchanged. Item customization exposes
to-hit override/bonus and damage bonus, but no die or range override.

Actions → Manage Custom → Weapon → new action → Edit supports:
Ranged, DEX, Dice Count 1, Die Type 6, Fixed Value 1, Piercing, Range 200,
Long Range 700, Activation Type Action, Proficient, Display as Attack.
Fixed Value adds to dice and the ability modifier: confirmed **1d6+2** on this
DEX +1 character. The attack list confirms **200 (700)** range. Inputs autosave
on blur; let each update settle before entering the next to avoid stale state.

The custom attack shows **+3**, not the required +4: it does not inherit the
inventory item's Magic bonus, and no independent to-hit bonus control was
exposed in its editor. Its snippet explicitly instructs adding +1 to hit or
using the original bow's +4 button. The original bow still shows incorrect
1d8+2 damage and 150/600 range; use the companion's damage button instead.
No dice rolls were executed; verified displayed formulas and controls only.

The companion is not linked to inventory equip state or future forge changes.
This is a partial workaround, not a finished one-click faithful importer.
No other equipment, abilities, or character settings were changed.
